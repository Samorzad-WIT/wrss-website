Dane do zebrania przed kodowaniem

  • Logo organizacji (SVG lub PNG)
  • Hasło / krótki opis WRSS
  • Link do serwera Discord
  • Zdjęcia + dane wszystkich przewodniczących i KOO
  • Zdjęcia z wydarzeń (KISSIT, Volvo 1, WITkon, Neurohakaton, rajdy, wydziałówki, bale, rejsy)
  • ID publicznego kalendarza Google
  • Treść Informatora studenta
  • Historia WRSS od 1945 (opcjonalnie)

Stack technologiczny

  • React + TypeScript + Vite
  • React Router DOM — routing między podstronami
  • Dane statyczne w src/data/members.ts i events.ts
  • Typy w src/types/index.ts
  • Zdjęcia w public/images/members/ i public/images/events/
  • Narzędzia QR / Winietki / Punkty = linki zewnętrzne
  • Koło fortuny = komponent React pod /narzedzia/kolo

Priorytety implementacji

  • 1. Navbar z dropdownem + hamburger mobile
  • 2. Sekcja Członkowie (dane statyczne)
  • 3. Hero + O nas
  • 4. Sekcja Wydarzeń z galerią
  • 5. Embed kalendarza Google
  • 6. Linki do narzędzi zewnętrznych
  • 7. Koło fortuny od zera

Ważne uwagi

  • Wizualizacja pokazuje układ i strukturę — ostateczny wygląd (kolory, fonty, animacje) ustala grafik
  • Iframe z zewnętrznych repozytoriów może być blokowany przez X-Frame-Options — wtedy link → nowa zakładka
  • Synchronizacja kalendarza Google z Facebookiem nie jest automatyczna — ktoś musi ręcznie dodawać wydarzenia
  • Responsywność mobile: karty członków 2 kolumny, menu hamburger — implementować na końcu
